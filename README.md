# Ankit Kumar — Full Stack Engineer Portfolio

An ultra-clean, modern, high-performance 2D developer portfolio built with **React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide Icons**. 

Designed with a premium SaaS aesthetic inspired by **Linear, Vercel, Apple, and Stripe**.

## ✨ Features & Architecture

- **SaaS Design System**: Dark theme (`#050508`), crisp typography, glassmorphism cards, and responsive bento grid layouts.
- **Interactive Tech Ecosystem Grid**: Filter technologies across Backend, Frontend, Datastores, Cloud, and AI with real-time code inspector previews.
- **Raycast Command Palette (`Ctrl + K`)**: Quick keyboard navigation across sections, instant email copying, and resume download.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ak8006181716/Portfolio.git

# 2. Navigate to the workspace
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
